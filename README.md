# AI Development Template v1

A Next.js App Router + TypeScript baseline for AI-led application development.

## Principle

Humans define requirements and important decisions. AI autonomously decides normal implementation details, implements, tests, self-checks, updates documentation, and commits completed work.

## Structure

- `AGENTS.md` — AI development entry point and common rules
- `agents/` — role-specific Agents
- `skills/` — repeatable work procedures
- `docs/` — canonical design/spec/security/decision documents
- `services/` — client/server service entry points
- `types/api/` — API response types
- `tests/` — test scaffold

## Usage

This repository is currently a template source. npm/`npx` generation is intentionally deferred.
